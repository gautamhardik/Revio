Pre-warmed in FastAPI worker threadpool. Ideal for zero cold-start latency, real-time live interactive typing, and explainable compliance auditing.

Bidirectional LSTM (Sequence Context)
Inference: ~45.2 ms Memory: 86.2 MB Embeddings: GloVe 100-dimensional

Sequential recurrent architecture capturing multi-phrase context and long-range negation dependencies (e.g. "not what I expected at all").

Inference: ~182 ms (CPU) Memory: 420 MB Parameters: 66 Million (DistilBERT)

Held-out deep transformer baseline for high-complexity arbitration when fast-path confidence falls into the ambiguity corridor.

Technical Model Attribution Details

Linear explainability via feature coefficient multiplication.

Revio computes instance-level feature attribution by extracting active unigrams, bigrams, and character 3–5 grams from the input text, calculating their term frequency-inverse document frequency ($\text{TF-IDF}$), and multiplying each by its linear logistic regression coefficient:

Contribution(term) = TF-IDF(term, doc) × β(term)

These weights are raw linear log-odds contributions ($X_j \beta_j$) in logit space. They are distinct from the review's estimated positive-class probability, which applies the logistic sigmoid function $\sigma(z) = 1 / (1 + e^{-z})$ over the sum of all linear contributions plus the bias term $\beta_0$.

Terms with positive weights pull the logit toward positive sentiment; negative weights pull toward complaint escalation.
